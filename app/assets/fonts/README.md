# Bundled fonts

Roboto (Regular, Medium, Bold) by Google, licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0). Bundled so the web app never
downloads fonts from Google's servers, which would reveal visitors' IP
addresses to a third party.

Noto Sans Bengali (Regular, Bold) by Google, licensed under the SIL Open Font
License 1.1. Used for Bangla text, because Roboto has no Bengali characters.
Taken from the @expo-google-fonts/noto-sans-bengali package (MIT wrapper; the
font files are the unmodified Google Fonts releases).
